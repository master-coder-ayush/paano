# Dashboard

The brand overview derives its space and campaign counts from source records and shows creators activated, posts published, total campaigns, and a basic next-action surface. Empty and missing-record states remain usable without seeded data.

## Version 2 Sprint 1

Brand and creator overview cards derive wallet, collaboration, profile, earnings, and message state from existing first-party records. Dashboard links are workspace-scoped and use the existing protected shell; empty collections render explicit copy. No new migration was required because the baseline wallet, collaboration, creator profile, published post, and notification tables already exist.
