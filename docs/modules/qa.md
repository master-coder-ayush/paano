# QA

V1 Sprint 7 smoke path: use the demo identities `?as=brand`, `?as=creator`, and `?as=admin`; verify `/brand/billing`, `/creator/earnings`, `/admin/review`, `/admin/billing`, and `/admin/payouts`. Confirm brand/creator requests receive permission-denied states, missing bearer tokens return 401, invalid transitions return 409/422, and balances are displayed from ledger records. Manual payment and payout processing are intentionally deferred.

V2 Sprint 7 regression checklist: verify the brand, creator, and admin notification centers show role-appropriate invitation, collaboration, publication, completion, withdrawal, review, and payment events; verify every notification deep link stays within the active role's protected routes; verify `/admin/review` shows creator, campaign, dispute, cancellation, withdrawal, and manual-payment queues; verify `/admin/support` shows operational queue counts; verify `?as=brand` and `?as=creator` receive permission-denied states for admin routes; verify missing, malformed, and non-admin bearer tokens are rejected by admin mutations; verify invalid review transitions return 409 and malformed payloads return 422. Empty, loading, failure, and permission-denied states must remain visible and localized.

V3 Sprint 7 checklist is maintained at `docs/qa/version-3-tracking.md` and covers click, pixel, duplicate, invalid-key, regenerated-key, disabled-link, attribution, privacy, and role-boundary scenarios.
