# Sprint Pack

This folder contains the execution plan for seven product versions. Each version has seven sprint files:

- `version-1`: foundation and manual marketplace.
- `version-2`: complete self-serve workflow.
- `version-3`: tracking, attribution, and real results.
- `version-4`: agencies, public growth tools, and content engine.
- `version-5`: enterprise codebase features and advanced automation.
- `version-6`: payments, payouts, AI assistance, and operational integrations.
- `version-7`: enterprise third-party integrations and multi-channel scale.

Before starting any sprint:

1. Read `docs/features.md`.
2. Read all previous sprint files in the same version.
3. Read or create the affected module docs listed in the sprint file under `docs/modules`.
4. Keep module docs updated as implementation and testing clarify behavior.
5. Confirm every protected change has server-side RBAC and every protected API/mutation endpoint requires an authentication header token.
